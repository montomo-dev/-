# 建設業向け 無料簡易サンプルのひな形

Instagram営業で「見たい」と返信をもらった工事店に送る、1ページの無料簡易サンプルのひな形です。
営業文（2026-10-14 13:13版）で案内している「施工例・工事の進め方・対応地域・相談窓口」の4つを、そのまま1ページに並べています。

## 相手用のサンプルを作る手順

1. `kensetsu` フォルダを相手名でコピーする（例：`aozora/`）。元のひな形は書き換えない。
2. コピー先の `data.js` だけを書き換える。相手の公開情報（公式サイト・Instagram）で確認できた内容だけを書く。
3. 施工写真は相手の公開写真のURLまたはファイル名を `photo` に入れる。未設定なら「施工写真をここに掲載」の枠が出る。
4. `node <コピー先>/check.mjs` を実行し、エラー0件にする。「注意」は仮の地名・写真なしなどの書き換え忘れ候補。
5. `index.html` をブラウザで開き、スマホ幅とPC幅で見て確認する。

## 書かないこと

- 相手の公開情報にない施工実績・お客様の声・資格・受賞歴・件数
- 納期・成果・維持費の範囲など、まだ決まっていない条件
- 個人情報を集めるフォーム（相談は電話・Instagram DM・LINE・メールへのリンクだけ）

## ファイル

- `data.js`：相手ごとに書き換える内容（ここだけ編集）
- `render.js`：data.js の内容をページに流し込む
- `index.html` / `style.css`：見た目（相手ごとには触らない）
- `check.mjs`：書き換え忘れ・空欄・窓口の食い違いの検査
- `screenshots/`：ひな形の表示確認（スマホ390px・PC1280px）

ページは `noindex` で、上部に「制作サンプル」の帯が出ます。公開・送信はこのひな形の作業に含みません。
