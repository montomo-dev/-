# 店舗向けホームページ制作サンプル

店舗・個人事業主向けのホームページ制作サンプル。実在店舗の実績ではなく、営業・提案用に作成したデモサイトです。

## 構成

- `index.html` … 1ページ構成（お店について / メニュー / お客様の声 / アクセス / お問い合わせ）
- `css/style.css` … 配色は先頭の CSS 変数で変更できます（主色 `--color-primary` など）
- `js/main.js` … スマホ用メニューの開閉と、サンプル用のフォーム動作

## 見かた

`index.html` をブラウザで開くだけです。ビルドや通信はありません。

## 作りで気をつけたこと

- 文字色と背景色のコントラストは、本文で 4.5:1 以上（WCAG AA）になるように調整
- キーボードだけでメニュー・フォームを操作できる（フォーカスの目印あり）
- フォームは送信せず、その旨を画面に表示（実案件ではメール送信等に差し替え）
